# Anchor Strength — Website Build Plan

## Goal
Build a fast, SEO-first **marketing website** for Anchor Strength (Boduppal, Hyderabad) that clearly out-classes the reference site (starfitnessstudio.in), with an editable content layer and a NestJS backend for lead capture. v1 = marketing only; architecture is pre-wired so member portal / booking / payments are a v2 extension, not a rebuild.

## How we beat the reference site
starfitnessstudio.in is a WordPress/Elementor one-pager with a WhatsApp button, a map, and a contact form — that's it. We'll beat it on:
- **SEO/SSR** — Nuxt 3 server-renders so "gym in Boduppal / calisthenics Hyderabad" actually ranks (their SPA-ish WP build is weak here). LocalBusiness/HealthClub schema, sitemap, OG tags.
- **Editable content** — headless CMS so the gym owner updates programs, pricing, testimonials, blog without a deploy.
- **Real lead funnel** — NestJS stores leads in Postgres + fires email/WhatsApp, vs. a dumb contact form.
- **Custom design system** — dark, athletic, "anchor" iconography, themed via a single config so real logo/photos drop in later.
- **Video/reels gallery + blog** — neither of which the reference has.

## Final tech stack (locked)
| Layer | Choice |
|---|---|
| Monorepo | pnpm workspaces (+ Turborepo for task caching) |
| Frontend | **Nuxt 3** (Vue 3 + TS), SSR marketing / SPA-ready portal, **Tailwind CSS + Nuxt UI** |
| Backend | **NestJS** (TS), modular: leads, contact, newsletter, health |
| ORM/DB | **Prisma** + PostgreSQL (SQLite for dev) |
| Content/CMS | **Strapi v5** (headless) — alt: Directus |
| Validation | class-validator + Zod on the frontend |
| API docs | NestJS Swagger at `/api/docs` |
| Email | Resend (transactional lead notifications) |
| WhatsApp | Click-to-chat deep links (no API cost) |
| Media | Cloudflare R2 (reels/photos) via CMS |
| Analytics | Plausible (privacy-friendly) |
| Infra/Deploy | Docker + docker-compose; Nuxt→Vercel/Netlify, API+CMS+DB→Railway/Render, Cloudflare DNS/CDN/WAF |
| Quality | ESLint + Prettier + TypeScript strict, GitHub Actions CI, Sentry |

## Phased delivery

### Phase 0 — Scaffolding & tooling
- `git init` inside `/Users/sudeep/ZCodeProject` (it's currently empty and *not* its own repo — `~` is a git repo; we'll init locally so the project is isolated).
- pnpm workspaces + Turborepo; root `package.json`, shared ESLint/Prettier/TS configs.
- `docker-compose.yml` for Postgres + Strapi + API (one-command local dev).
- `.env.example` files, `.editorconfig`, `.gitignore`, `README.md` with setup steps.

### Phase 1 — Design system & theming (placeholders)
- Tailwind theme tokens in `apps/web/app.config.ts` / CSS vars: `--brand`, `--accent`, radius, fonts (bold condensed display + clean body).
- `theme.config.ts` central file: logo path, brand colors, phones, address, hours, socials, IG handle — **single source of truth** so swapping placeholders for real assets is trivial.
- Reusable layout primitives: `AppHeader`, `AppFooter`, `Section`, `Container`, `Button`, `Badge`, `Card`. Sticky header + scroll-spy nav + mobile drawer.
- Floating WhatsApp + click-to-call buttons (matches/beats reference's WhatsApp widget).

### Phase 2 — NestJS backend (`apps/api`)
- Prisma schema: `Lead`, `ContactMessage`, `NewsletterSubscriber`, `AuditLog`. Postgres prod / SQLite dev.
- Modules: `LeadsModule` (free-trial request), `ContactModule` (contact form), `NewsletterModule`, `HealthModule` (`/health`), shared `NotificationsModule` (Resend email + WhatsApp link builder).
- DTOs with class-validator, global `ValidationPipe`, Swagger at `/api/docs`, CORS config, rate-limiting, request logging.
- Endpoints: `POST /api/leads`, `POST /api/contact`, `POST /api/newsletter/subscribe`, `GET /api/health`.
- Seeds the future v2 surface (auth/members/bookings/payments add modules, don't restructure).

### Phase 3 — Strapi CMS (`apps/cms`) content model (real Anchor Strength data)
Content types, pre-seeded with researched data:
- **Brand** (singleton): name, taglines ("Boduppal's 1st Calisthenics Gym", "Join a team, not just a gym!"), phones (+91 93790 66066 / +91 79894 58980), address (Boduppal Rd, above SBI Bank, Mallikarjuna Nagar, Hyderabad - 500092), hours (5 AM–10 PM, 365 days), socials (`@anchorstrengthofficial`).
- **Program** (collection) — 12 disciplines: Gym, Personal Training, Kettlebell Group Training, MMA, Calisthenics (flagship), Yoga, Dance, Animal Flow, Mudgars, Steel Mace, Arm Wrestling, Sport Events. Fields: title, slug, icon, short description, long description, image, isFlagship.
- **PricingPlan** (collection) — headline ₹1,500/mo; ₹13,500/24-mo; "limited offer" tiers flagged as promo; fields: name, price, period, INR, features[], isPromo, ctaLabel.
- **Trainer** (collection) — name, specialty, photo, certifications, bio (placeholders for now).
- **Testimonial** (collection) — pulled from Justdial/Tripadvisor (5.0 rating, ~131 reviews); name, quote, rating, source.
- **GalleryItem** (collection) — image/video, type (photo/reel), caption.
- **Faq** (collection) + **Article** (collection) for blog/SEO.
- Read-only API token for Nuxt; CORS allow localhost + prod domain.

### Phase 4 — Nuxt marketing site (`apps/web`)
One home page with anchored sections (matches reference's structure, expands it) + a few standalone routes:
- `/` → **Hero** ("Boduppal's 1st Calisthenics Gym" + 12-discipline proof) → **About / Why Us** → **Programs** (filterable grid of 12) → **Pricing** (lead ₹1,500/mo + promos) → **Gallery** (photos + reels) → **Testimonials** (carousel, 5.0★ social proof) → **FAQ** → **Contact** (form → NestJS, + Google Map embed of Boduppal, hours, phones).
- `/programs/[slug]` — individual program detail pages (SEO long-tail: "calisthenics Hyderabad", "MMA Boduppal"). Reference has none.
- `/blog` + `/blog/[slug]` — content marketing for SEO (reference has none).
- `/contact` — dedicated lead/trial-booking route.
- Components consume CMS via a typed `useContent()` composable + `useAsyncData` (SSR + ISR caching).
- Lead forms post to NestJS API with loading/error/success states + honeypot + basic validation.

### Phase 5 — SEO, performance & integrations
- **Schema.org**: `HealthClub`/`LocalBusiness` JSON-LD (name, address, geo, openingHours, phone, aggregateRating from reviews).
- `@nuxtjs/sitemap`, `@nuxtjs/robots`, canonical URLs, OG/Twitter cards, `nuxt-schema-org`.
- Performance: image optimization (`@nuxt/image`), font subsetting, route rules for ISR on CMS-driven pages, Lighthouse target ≥ 90.
- Analytics: Plausible; optional GA4.
- Error pages (`error.vue`), 404, loading states.

### Phase 6 — Deploy & CI/CD
- GitHub Actions: lint → typecheck → build → test on PR.
- Dockerfiles per app; `docker-compose.prod.yml`.
- Deploys: Nuxt→Vercel (Nitro preset), NestJS+Strapi+Postgres→Railway/Render; Cloudflare in front (DNS + CDN + WAF + R2 media).
- Sentry for error tracking; uptime checks.

## v2 (deferred, architecture pre-wired)

## Assumptions / notes
- All branding uses clean placeholders driven by `theme.config.ts`; you swap logo/photos/colors later with no layout changes.
- Content (programs, pricing, testimonials) seeded from public research; you confirm/adjust exact prices & copy in Strapi before launch.
- Domain not yet purchased — deployment step assumes you'll provide one (e.g. anchorstrength.fit).
- Instagram posts/reels are login-gated, so gallery uses placeholders until you export media into the CMS/R2.
